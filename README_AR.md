# Al-Israa QC Manager 4.0.0 — نسخة اختبار متكاملة محلياً

## ما تحتويه النسخة
- PWA عربية متجاوبة، تخزين IndexedDB محلي، وعمل دون اتصال بعد أول تحميل ناجح.
- أجهزة منفصلة، وأهداف QC لكل جهاز/تحليل/LOT/مستوى. الهدف مسودة ولا يدخل التشغيل قبل اعتماده.
- تسجيل تشغيل متعدد المستويات مع لقطة ثابتة للهدف والسياسة والمصدر وقت التشغيل.
- محرك حساب Z-score وCV، وقواعد قابلة للتفعيل حسب سياسة الجهاز والتحليل: 1_2s (تحذير فقط)، 1_3s، 2_2s، R_4s بين مستويين ضمن التشغيل نفسه، 4_1s، 10x، 7T، 8x.
- سجل تشغيل، ملخص إحصائي وصفي، ومخطط Levey–Jennings.
- سجلات المعايرة وEQA/PT والإجراءات التصحيحية وسجل تدقيق محلي.
- تصدير CSV وطباعة التقرير/حفظ PDF من نافذة الطباعة، ونسخ احتياطي JSON واستعادة بدمج البيانات دون مسح السجلات الحالية.

## تشغيل محلي
افتح المجلد عبر خادم HTTPS/localhost؛ لا تفتح index.html مباشرة لأن Service Worker يتطلب secure context. يمكن نشر الملفات الثابتة كما هي على Cloudflare Pages، ويكون مجلد النشر هو جذر هذا المجلد.

## الاختبار الآلي
يتطلب Node.js 18+:
`node tests/qc-engine.test.cjs`

## تنبيه علمي وتشغيلي مهم
هذه نسخة اختبار موازٍ وليست نظاماً معتمداً سريرياً أو بديلاً عن SOP. قواعد Westgard وتواترها ونطاق تطبيقها يجب اعتمادها من المختبر لكل جهاز/تحليل. بعض القواعد التسلسلية تحتاج نقاطاً سابقة؛ عند عدم كفاية البيانات يعرض النظام «تقييم غير مكتمل» ولا يعتبر ذلك قبولاً. لا يوجد تكامل أجهزة/LIS، مزامنة سحابية، صلاحيات مستخدمين، أو مراقبة تلقائية لمصادر APS/TEa. لا تدخل بيانات تعريف المرضى. يجب مقارنة الحسابات والقرارات بحالات يدوية معروفة قبل الاستخدام التشغيلي.

## حماية البيانات
البيانات محلية على المتصفح/الجهاز. احتفظ بنسخ JSON خارج الهاتف. تحديث Service Worker لا يحذف قاعدة IndexedDB. لا تحذف بيانات Safari أو بيانات الموقع أثناء الاختبار.
